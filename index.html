Milestone 003 / Programmatic control · 23 Oct 2026

Python-controlled takeoff and landing

An original Python script connected to PX4 via MAVSDK 4.0.6 and commanded arming, takeoff, a timed wait, and landing in Gazebo Walls World. PX4 reported takeoff, landing, and automatic disarm.

External command · takeoff · landing · disarm

Simulator only. Timed wait is not a measurement of hover accuracy; no obstacle avoidance was tested.

02 / Verification

What the tests
actually establish.

Each claim is limited to the observed simulator behavior. This is an experimental record, not a demonstration of operational readiness.

TEST ENVIRONMENT

Software-in-the-Loop

PX4 autopilot, Gazebo Harmonic X500, QGroundControl, and Python 3.12.3 with MAVSDK 4.0.6. M003 was conducted in the Gazebo Walls World simulation.

RECORDED EVIDENCE

Console events & flight logs

Takeoff, landing and disarm are checked against PX4 events. The M002 log backup was verified with SHA-256; the M003 log was recorded but its independent hash verification remains pending.

OUTSIDE CURRENT SCOPE

No claims of field autonomy

No physical drone trials, sensor-driven obstacle avoidance, autonomous search, waypoint tracking accuracy, or deployment in a real disaster environment have been demonstrated.

03 / Approach

Build the loop.
Then add autonomy.

The project develops from dependable simulation and documented flight behavior toward software-defined missions. Small tests make failures visible and progress reproducible.

01 — SIMULATE

Set up a safe test loop

Use a Software-in-the-Loop environment to practice flight control and observe system behavior before adding mission complexity.

PX4 · Gazebo
02 — MEASURE

Record what happened

Capture flight steps, outcomes, and logs so that each run can be checked and repeated with a clear baseline.

FLIGHT LOGS · SHA-256 VERIFICATION
03 — EXTEND

Write the mission in code

Move from manual test sequences toward Python-authored missions, then evaluate autonomous exploration in a virtual disaster-site scenario.

THE PERSON BEHIND UAS AUTONOMY LAB

I lead UAS Autonomy Lab, an independent project focused on hands-on experiments with autonomous systems, simulation, and practical engineering. My interests span aviation, maritime operations, space technology, and how digital tools can support work in the physical world.

Currently, I am developing and documenting PX4-based flight simulations and Python-controlled experiments. I aim to build verifiable technical capabilities, learn from people working in the field, and explore collaboration around real operational challenges.
